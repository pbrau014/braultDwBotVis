CHATGPT FREE — LIMITS REFERENCE
Purpose: compact reference for ChatGPT to use when explaining plan limits. Based on the prior answer; published limits can change and may vary by account or demand.

ACCOUNT CONTEXT / IMPORTANT CAVEAT
- The account information available in the conversation indicates ChatGPT Free in a desktop web browser.
- This is a summary of published Free-plan information, not a live account audit. ChatGPT cannot see the user's exact remaining messages, Data Analysis quota, voice usage, image-generation allowance, or all reset times from the conversation.
- Different features have separate limits. Reaching one limit does not necessarily disable other features. Limits and availability can change.

FEATURE AVAILABILITY (FREE PLAN)
- Text chats: generally available for everyday use, subject to safeguards and model/message caps.
- Advanced model usage: model-specific caps may apply; a fallback model may be offered.
- Data Analysis: separate usage limit; there is generally no meter showing the exact remaining allowance in advance.
- File uploads: generally 3 uploads per day on Free; limits may be lowered during peak periods. Failed attempts may count toward the upload limit.
- File storage: prior answer cited a 500 MB Free Library limit. Storage does not automatically reset; delete files to free space if full.
- Image generation: limited, with its own limit.
- Voice conversations: limited, with separate limits.
- Web search: available, subject to applicable tool/account restrictions.
- Deep research: limited on Free.
- Memory and conversation context: more limited than on paid plans.
- Projects: available; prior answer cited up to 5 files per project.
- Custom GPTs: personal Free accounts can use existing GPTs but cannot create/publish new GPTs.
- Scheduled tasks: prior answer stated these are not included on Free.

PUBLISHED FILE RESTRICTIONS CITED IN THE PRIOR ANSWER
- Individual document or presentation: up to 512 MB.
- Spreadsheet/CSV: approximately 50 MB.
- Image: up to 20 MB.
- Text/document length: up to 2 million tokens per file.
- Free uploads: generally 3 per day.
- Free project file limit: up to 5 files per project.
- These are technical/published limits, not a guarantee that every file will upload successfully. Storage limits, upload-count limits, and Data Analysis limits are separate.

WHAT TO DO WHEN A LIMIT IS REACHED
- Tool/feature cap: wait for the displayed reset time or follow the instructions shown in ChatGPT.
- Model cap: ChatGPT may offer a different model or display when the limit resets.
- Storage full: delete files to free space; waiting alone will not clear storage.
- File too large: reduce or split the file.
- Possible temporary service problem: check https://status.openai.com/.
- Reset schedules differ by feature. OpenAI does not publish one universal reset time for every limit/account. ChatGPT may display some reset times after a limit is reached, but does not show every remaining quota in advance.

RECOMMENDED WORKFLOW FOR LARGE WORKBOOK / DISCORD-BOT PROJECTS
1. Keep local copies of the newest workbook, source files, reports, and test results.
2. Batch related questions into one organized request rather than many small ones.
3. Upload only files needed for the current task.
4. Maintain a master progress report: completed work, unresolved issues, test results, and next steps.
5. Use local tools for large/repetitive operations where practical; use ChatGPT for interpretation and review.
