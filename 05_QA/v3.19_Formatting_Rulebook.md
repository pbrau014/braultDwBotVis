# v3.19 Formatting Rulebook

<div style="background-color:#DFF2FF; border:1.5px solid #0070C0; padding:6px 8px; margin:4px 0;"><strong>⚓ Quick hint:</strong> Check the stated authority, required evidence, and completion criteria before acting; do not infer an approval that is not recorded.</div>
Status: applied to the v3.19 current publications and companion Word files; source baselines remain immutable.

## Hierarchy and page structure
- Retain the v3.18 visual system: navy/blue headings, controlled shadow-like headings, white/pale-blue table banding, strong dark outside borders, and readable inner borders.
- Preserve the existing title/chapter/appendix/contents hierarchy unless a targeted reflow improves readability without moving substantive content.
- Use semantic Word paragraph styles and controlled spacing; do not introduce repeated blank paragraphs as a layout technique.
- Preserve the full repeated-anchor chapter divider as the expressly authorized A2 exception.

## Text units and icons
- Ordinary prose, list items, and table cells use at most one pictographic icon per text unit. Remove redundant decorative icons from mixed timing/numbered lines.
- The repeated-anchor divider is the sole deliberate multi-icon exception under A2.
- Standardize the source Markdown callout as `✅ **Done when:** ...`; no doubled emphasis marker should follow the colon.
- In Word, `Done when` callout text is 8.5 pt. Retain readable leading/line wrapping and avoid clipping.

## Tables
- Use blue header shading and alternating white/pale-blue body fills, heavier dark outer borders and slightly lighter inner rules.
- Prioritize preserving numeric values, test labels and whole rows. Adjust column widths and reflow before reducing font sizes.
- Keep the Event Settings baseline table rows intact across page breaks when practical.
- For numeric comparison cells, allow wrapping at separators/spaces, not inside a numeric literal.

## References and status labels
- For same-document references, use the established section or appendix identifier. For cross-publication references, name the destination publication explicitly.
- Keep document version, filename, cover version and running headers synchronized.
- Preserve explicit DRAFT, WORKING DRAFT, NO-GO, BLOCKED, NOT RUN and NOT APPROVED labels. A missing/waived/unperformed test is never a pass.

## Format-specific behavior
- Markdown preserves semantic headings, lists, tables, links and emphasis; it is not expected to reproduce exact PDF page layout or Word-only visual effects.
- Render Word documents to PDF after changes. Review every available current PDF page at full size and compare source to output.
- Outgoing hyperlink destination testing remains outside the scope set for this project.
