# Synthetic validation exports

These files were generated by exercising the bot's real command handler with mocked Discord messages and deterministic pseudo-random test values. They are **test data only**, not real player results. Do not import them into a live tournament except for a deliberate restore test.

- `synthetic-workbook-backup.json` — version-2 backup with `players` and `settings`; designed to match the source HTML workbook importer.
- `synthetic-full-state-archive.json` — bot recovery snapshot with workbook-compatible state, two synthetic OCR records, and one resumable OCR correction. Used to verify full archive import and resume.
- `synthetic-final-tournament-export.json` — final snapshot generated through `!yolo finalize`; the summary records 3 players and 84/84 filled slots.
- `synthetic-system-validation-report.json` — test inputs/settings plus export and snapshot validation details.

- `workbook-h12-audit-result.json` — verified source-of-truth values from the bundled Excel workbook: `Totals!H12` is $12.49 for the default data, and the source formula remains intact.
