EXECUTIVE SUMMARY

The iteration-20 implementation adds a local-only PaddleOCR field-crop fallback to the existing Tesseract.js pipeline. The fallback is disabled by default, activates only for unresolved, ambiguous, or contradictory required fields, uses only explicitly configured local model directories, and never writes raw PaddleOCR text directly to the tournament record. Candidate strings pass through the same field parsers and record consensus. Merged reward values are rejected; OCR-confusable O/0-style player conflicts are preserved as unresolved for human review. Crop count, geometry, and time budgets are bounded, and the Python worker blocks socket connections before importing PaddleOCR.
